# System Logic Tree — شجرة منطق النظام

نسخة 2026-10-06. هذه هي شجرة المنطق المرجعية للمشروع. العناوين بالإنجليزية بأسمائها الحقيقية، وبعد كلّ عنوان
شرحٌ عربيٌّ قصير. كلّ رقمٍ ونسبةٍ مقروءٌ من الكود.

هذه الشجرة تعرض **ما هو قائمٌ وعاملٌ فقط**. البنود المعطّلة وقائمةُ
العمل والبنودُ تحت الدراسة في لوحة البنود المفتوحة، لا هنا.

```
TRADING SYSTEM — نظام التداول
│

├─ 2. UNIVERSE BOUNDARY — حدود الكون: ما يُستبعَد قبل أيّ مرحلة

│   ├─ Rule 2: Leverage Word — كلمةُ رفعٍ أو انعكاسٍ صريحة: فائق، مرفوع،
│   │                           معاكس، هابط
│   ├─ Rule 3: "Short" as Direction — كلمةُ «قصير» بمعنى الانعكاس
│   │   └─ Duration Exception — «قصيرُ الأجل» و«قصيرُ المدّة» و«سنداتٌ قصيرة»
│   │                            مُدّةٌ لا اتّجاه، فلا تُستبعَد
│   ├─ Why Excluded — لماذا يُستبعَد المرفوع والمعاكس
│   │   ├─ السلّم يشتري أكثرَ عند الهبوط، والمعاكس يهبط حين يصعد السوق
│   │   ├─ والمرفوع بضعفين يقطع -5% و -8% و -10% في أيامٍ معدودة،

│   ├─ Name Not Ticker — بالاسم لا بالرمز، لأنّ قوائم الرموز تَبلى بإعادة التسمية
│   ├─ Missing Name Passes — أداةٌ بلا اسمٍ تُعَدّ مؤهّلة، لأنّ «لم نتحقّق»
│   │                         ليس دليلَ رفعٍ مالي — ولهذا يُعرَض عددُ المستبعدين
│   └─ Narrow Scope — النطاق ضيّقٌ بالقصد: الصناديقُ العاديةُ ما زالت تمرّ
│
├─ 3. DAILY SELECTION PIPELINE — المصفاة اليومية، المدخل نحو 12,589 أداة
│   ├─ Measures From Bars — أرقام المرشّحات تُحسَب من آخر 45 شمعةً يومية
│   │   ├─ Liquidity — Volume × Weighted Price for last 20 days (السيولة * السعر الرجح)
│   │   ├─ Volatility — مقياس التذبذب (Volatility) (ATR — Average True Range) for last 14 days
│   │   ├─ Momentum — لزخم السعري تغيّر سعر الإغلاق الحالي مقارنةً بسعر الإغلاق قبل 30 شمعة يومية. اتجاه وحجم الحركة خلال الفترة الأخيرة
│   │   └─ Spread Proxy — متوسّط (الأعلى − الأدنى) ÷ المرجَّح لآخر 20 شمعة،
│   │                      وهو مؤشّرٌ بديل لأنّ التغذية المجّانية لا تُعطي
│   │                      عرضاً وطلباً حقيقيين
│   ├─ Stage A — Tradability — القابلية للتداول
│   │   ├─ يُحتفَظ بأعلى 30% سيولةً
│   │   └─ ويُحذَف أدنى 20% سعراً
│   ├─ Stage B — Data Quality — جودة البيانات
│   │   └─ اكتمالُ البيانات ≥ 90%
│   ├─ Stage C — Execution Quality — جودة التنفيذ
│   │   └─ فرقُ السعر ≤ 0.15% من السعر، ويُطبَّق فقط مع عرضٍ وطلبٍ حقيقيَّين
│   │       Relative Rule Removed — قاعدةُ أعلى 40% إحكاماً أُزيلت في D-0088
│   ├─ Stage D — Strategy Fit — ملاءمة الاستراتيجية، المرحلة الحاسمة
│   │   ├─ التذبذبُ بين 2% و 4% من السعر
│   │   ├─ Below 2% — السلّم لا يُشعَل أصلاً، فيبقى ثلاثةُ أرباع الميزانية عاطلاً
│   │   ├─ Above 4% — يُقطَع السلّمُ كلُّه في يومين، فتصير الأرضيةُ النهايةَ المعتادة
│   │   ├─ والاتّجاهُ في أعلى 50%
│   │   └─ وتقتل نحو 77.5% مما يصلها، مقيساً بعد D-0088
│   ├─ Stage E — Regime Adaptation — (هل نُعدّل عملية اختيار الأسهم بناءً على حالة السوق/الاقتصاد الكلية الحالية؟)التكيّف مع النظام الاقتصادي
│   │   ├─ إن كان الخوف في أعلى 20% تاريخياً لهذا السهم ، يحتفظ فقط بأفضل 50% من الأسهم من ناحية الزخم (Momentum).   

│   ├─ Stage F — Ranking — الترتيب
│   │   └─ Quality Means —  الزخم 40% + الجودة 30% + السيولة 30%
│   ├─ Stage G — Concentration — التنويع القطاعي
│   │   └─ لا قطاعَ يتجاوز 30% من الناجين، على من يُعرَف قطاعُه
│   ├─ Stage H — Top-N — أعلى عشرة، وتُنشَر لقطةُ اليوم
│   └─ Measured Funnel — القياس بعد D-0088: نحو 640 ناجياً قبل أعلى-عشرة، وكان 26 قبله
│
├─ 4. REGIME CLASSIFIER — (تحديد حالة السوق العامة (Market Regime) التي يعمل فيها النظام.Risk-On, Neutral, Risk-Off)النظام الاقتصادي
│   ├─ Window —  (يقارب عدد أيام التداول في سنة واحدة)تاريخُ سنةٍ لمؤشّر الخوف، ويُحتفَظ بآخر 252 ملاحظة
│   ├─ Percentile — (بعد Window)نسبةُ اليوم = حصّةُ التاريخ الأدنى منه
│   ├─ Labels — (بعد Percentile)≤ 33% تحمُّلُ مخاطر، ≥ 66% نفورٌ منها، وبينهما محايد
│   ├─ Fail-Open — عند أيّ عطل: 50% و«غيرُ مصنَّف»، ولا انهيارَ أبداً
│   └─ Two Effects — للنفور أثران: تضييقُ المرحلة الخامسة،
│                     ورفضٌ قاطعٌ لكلّ مرشَّحٍ في التقييم

├─ 5. CRASH vs EMPTY — انهيارٌ أم فراغ، تفرقةٌ يفرضها نظام الأنواع
│   ├─ Crash — خطأٌ تقنيٌّ أو حالةٌ فاسدةٌ أو عطلُ بنية
│   │   └─ لا تُنشَر لقطةٌ إطلاقاً، فتبقى لقطةُ اليوم الجيّدةُ سليمة
│   └─ Empty — الأنبوبُ أكمل مسارَه ولم ينجُ أحد
│       └─ تُنشَر لقطةٌ صحيحةٌ بعلامة «فارغة» وسببٍ محدّد، وتصير أحدثَ لقطة
│
├─ 6. EVIDENCE LAYER — طبقة الأدلّة، حاجزٌ معماريٌّ متعمَّد
│   ├─ Applied After — تُطبَّق بعد أن ينتهي الأنبوبُ من الاختيار
│   ├─ Invisible To Stages — ومراحلُ الاختيار لا يجوز أن تعرف بوجودها
│   └─ Not-Eligible Dropped Here — «غيرُ المؤهّل» يُحذَف هناك، لا في أيّ مرحلة
│
├─ 7. NO-UNIVERSE RULE — قاعدة اللقطة
│   ├─ No Snapshot = No Trade — لا لقطةَ اليوم، فلا تداولَ اليوم
│   └─ No Fallback — لا قائمةَ احتياط، ولا رموزَ افتراضية، ولا عودةَ إلى لقطة أمس
│

│   ├─ Hard Filter — فحصٌ قاطع، والرفضُ فوريّ
│   │   ├─ No Live Price — لا سعرَ حالي
│   │   ├─ Earnings Soon — أرباحٌ خلال 7 أيام
│   │   ├─ Low Volume — حجم التداول اليومي للسهم < 100,000 سهم
│   │   ├─ RSI Extreme — قوة الحركة السعرية الأخيرة > 90 أو < 10
│   │   ├─ Risk-Off Regime — نظامٌ اقتصاديٌّ نافرٌ من المخاطر
│   │   └─ Political Sell Wave — ثلاثةُ بائعين أو أكثر في 30 يوماً
│   ├─ Soft Score — (درجة نهائية)درجةٌ موزونة، مجموعُها 90
│   │   ├─ Technicals — 20
│   │   ├─ Fundamentals — 16
│   │   ├─ Political — 15
│   │   ├─ Trend — 13، عوائدُ 5 و 30 و 90 يوماً

│   │   └─ Risk Discount — (إذا كانت هناك مخاطر تستحق الخصم.)حتى -20
│   ├─ News Polarity — قطبيّةُ الأخبار بقاعدةٍ حتميةٍ لا بنموذجٍ لغوي
│   │   ├─ Formula — (المحفّزات − المخاطر) ÷ (المحفّزات + المخاطر)
│   │   ├─ Range — كلُّها محفّزات +1، ومتوازنة 0، وكلُّها مخاطر -1
│   │   └─ No Data ≠ Neutral — ولا شيءَ يعني «لا معلومة»، لا «محايد»،
│   │                            فانقطاعُ المصدر لا يُنتج حكماً زائفاً
│   ├─ Acceptance Bar — حاجزُ القبول: الدرجةُ ≥ 60
│   └─ Fund Ceiling — سقفُ الصندوق: 90 − 16 − 15 = 59، وهو أقلُّ من 60

│   ├─ Whitelist — 15 سياسيّاً، وأوزانُهم بين 1.0 و 1.5

│   ├─ Daily Cap — بحدٍّ أقصى 5 رموزٍ سياسيةٍ في اليوم
│   └─ Reserved Slot — الخانة المحجوزة
│       ├─ واحدةٌ من مقترحات الدورة لأفضل مرشَّحٍ مدعومٍ سياسياً
│       ├─ Must Pass Everything — بشرط اجتياز المصفاة والفحصِ القاطع وحاجزِ الستّين
│       ├─ No Exemption — لا إعفاءَ من فحص، ولا إدخالَ لمن رسب
│       ├─ Earned Already — وإن دخل أحدُهم باستحقاقه فلا حجز
│       ├─ No Waste — وإن لم يوجد مؤهّلٌ تعود الخانةُ طبيعيةً ولا تُهدَر

├─ 13. TWO RISK LAYERS — طبقتا فحص المخاطر

├─ 14. APPROVAL WORKFLOW — الموافقة
│   ├─ Nothing Without You — لا شيءَ يُنفَّذ قبل موافقتِك الصريحة
│   ├─ Approval Window — والموافقةُ صالحةٌ خمسَ دقائق
│   ├─ Revalidation — وقبل الإرسال إلى الوسيط تُعاد أربعةُ شروطٍ مجتمعة

│   │   ├─ Age — وعمرُ الموافقة ≤ 5 دقائق
│   │   ├─ Price Band — وانحرافُ السعر عن سعرِ الإشعال ≤ 0.5%
│   │   └─ Floor Priority — وسعرُ الدخول أعلى من الأرضيةِ النشطة

│   ├─ Submission Is Authoritative — الفحصُ عند الإرسال للوسيط هو المرجع، لا المبكّر
│   └─ Transport Agnostic — (المحرّك نفسه لا ينبغي أن يعرف هل الموافقة جاءت عبر)نقلُ الموافقة مُجرَّد، فلا أحدَ في الأعلى يعرف وسيلتَه

├─ 15. POSITION SIZING — الحجم
│   ├─ Trade Budget — ميزانيّةُ الصفقة 5% من حقوق الملكية
│   ├─ Split — الدخولُ الأوّل 25%، والسلّمُ الأوّل 25%، والسلّمُ الثاني 50%
│   ├─ Min Shares — وبحدٍّ أدنى سهمٌ واحدٌ لكلّ طبقة
│   ├─ Worked Example — على مئةِ ألف: الميزانية 5,000 ← 1,250 و 1,250 و 2,500
│   └─ No Silent Fallback — مَن لم يُقدِّم حقوقَ ملكيةٍ وسعراً صحيحين
```
